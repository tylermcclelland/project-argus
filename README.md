# project-argus
Design and implement a tool that will allow computer users to identify attacks or suspicious activity on their local network using a Raspberry Pi and a web-based dashboard. By default, the user plugs the Raspberry Pi into an open ethernet port on their router. In this mode it monitors broadcast and multicast traffic (ARP, DHCP, mDNS) and builds an inventory of devices on the network, which lets it detect threats such as ARP spoofing, rogue DHCP servers, and unknown devices. For full traffic visibility, the Pi can also be deployed as a gateway or connected to a mirrored (SPAN) port on a managed switch, which adds detection of port scans and other traffic-based attacks. Detected threats are flagged on the dashboard with plain-language guidance on how to respond. Because most traffic is encrypted, the system analyzes packet headers and traffic behavior rather than contents. It is detection-only, stores all data locally, and is intended only for networks the user owns or is authorized to monitor. This project will enable everyday people to easily monitor their network and protect themselves against network attacks.
